# Modules Ncare

Bibliothèque de capsules pédagogiques interactives (HTML autonome, format mobile) des programmes **Ncare**, le compagnon numérique des parcours proposés par la clinique **Selinoa**.

Trois programmes :

- **Breathe** — capsules respiration (M01–M03)
- **Maintain** — parcours métabolique / habitudes (M01–M12)
- **Sérénité** — parcours charge mentale, stress et sommeil (S01–S12, en français)

## Diffusion

Les capsules sont servies aux participantes via GitHub Pages. **Les noms de fichiers servent d'URL** : ne jamais renommer ni déplacer un fichier déjà diffusé sans mettre à jour le lien correspondant dans l'application Ncare. Chaque page porte une balise `noindex` afin de ne pas être référencée par les moteurs de recherche.

## Convention de nommage

`Ncare_<Programme>_<Numéro>_<Thème>.html`
exemple : `Ncare_Serenite_S04_Matin.html`
